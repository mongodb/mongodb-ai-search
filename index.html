How SearchaaS works

The retrieval pipeline, end to end

Every box is clickable and jumps to the doc that covers it. A query flows left to right: an agent calls REST or MCP, the factory pipeline understands, plans and retrieves, and MongoDB Atlas does the heavy lifting.

request flow LLM calls (understand · plan · summarize) grounded response back to the agent

Agents × SearchaaS

How an agent answers a question

The Employee Support Copilot is the reference agent: five steps from user question to grounded, cited answer — each step links to its doc.

1

Ask in chat

User asks in the Next.js UI; the BFF receives POST /api/chat.

 2

Classify domain

Keyword classifier routes to IT_helpdesk or employee_support.

 3

Call SearchaaS

POST /retrieve with per-request atlas overrides — collection, indexes, weights.

 4

Understand → plan → retrieve

Query understanding + LLM planner pick a strategy; Atlas executes the pipeline.

 5

Ground & cite

Answer rendered with domain badge, strategy chip, timings and citations.
